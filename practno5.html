Responsive Design

Why Are Breakpoints Important?

Responsive breakpoints allow a website layout to change according to the size of the user's screen.

📱

Mobile

On mobile phones, the website uses a single-column layout. The navigation changes into a menu and content is given more vertical space.

Tailwind: sm:
📱

Tablet

On tablets, more horizontal space is available. The website can display two columns and provide a wider navigation layout.

Tailwind: md:
💻

Desktop

Desktop screens provide more space, allowing multiple columns, larger images, complete navigation and wider content sections.

Tailwind: lg:

Tailwind Breakpoints

One Website, Multiple Screen Sizes

Tailwind lets developers change the design at different screen widths without writing separate media queries for every component.

Example:

grid-cols-1
md:grid-cols-2
lg:grid-cols-3

Mobile → 1 column
Tablet → 2 columns
Desktop → 3 columns
