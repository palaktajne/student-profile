Traditional CSS Example

How Traditional CSS Works

A developer first creates a class such as .college-info and then defines its background, padding, border, shadow and other properties in CSS.

.college-info {
  background: white;
  padding: 30px;
  border-radius: 16px;
  box-shadow: ...;
}
